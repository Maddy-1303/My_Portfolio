01 · Applaunch

RAG-based AI Chatbot

Architect · in progress

Problem
Medical learners need accurate answers grounded in verified course content, not hallucinated responses.
Impact
Grounded, verifiable AI answers over medical content. Status: architecture and implementation in progress.
  • Ruby on Rails
  • Node.js
  • Vector DB
  • Embeddings
  • LLM APIs
What I'm building
A retrieval-augmented generation pipeline as a separate Node.js service alongside the Rails app. Course content is chunked, converted to embeddings and stored in a vector database. At query time the question is embedded, similar chunks are retrieved, and that context is passed to the LLM so answers are grounded in real source material. The work includes evaluating answer accuracy and hallucination against the source content.
